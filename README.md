# Platin

Holt jede Stunde deine PlayStation-Trophäen und speichert sie in `docs/trophies.json`.
Die App „Platin.“ in Claude zeigt sie an.

- Läuft bei GitHub Actions, der PC muss nicht an sein.
- Braucht das Secret `PSN_NPSSO` (Settings › Secrets and variables › Actions).
- Der Schlüssel läuft etwa alle 2 Monate ab – dann einfach einen neuen eintragen.
- Sofort abrufen: Actions › „Trophäen abrufen“ › Run workflow.
